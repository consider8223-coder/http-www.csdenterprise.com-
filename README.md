# CSD Enterprise

Official website source for CSD Enterprise, a multidisciplinary Nigerian company based in New Road, Borikiri, Port Harcourt, Rivers State.

## Website pages

- Home
- About Us
- Services
- Contact Us

## Services featured

- Industrial Training
- AI Generative
- Graphic Design
- Video & Music Generation
- General Contracting

## Technology

The site is built with Next.js, React, TypeScript, Tailwind CSS, Vite, and Vinext. It includes a responsive desktop/mobile navigation system, a customized CSD logo, social-sharing metadata, and locally stored image assets.

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm ci
npm run dev
```

## Validate a production build

```bash
npm test
```
